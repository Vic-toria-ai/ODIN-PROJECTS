Functions are the main "building blocks" of a programme. They allow code to be called many time`s without repetition.

To create a function, you need a function declaration, and it looks something like this:
function functionName (parameters){
function body
}

N.B A LIST OF PARAMETERS ARE SEPARATED BY COMMAS.

You usually call a function by using the function name followed by parentheses. It is called outside the function definition.

Parameters are used to pass information into a function when it is called.
